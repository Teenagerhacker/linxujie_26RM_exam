# 26RM 全向轮步兵双板控制工程

浙江大学 Hello World 电控组 2026 招新考核工程。项目基于两块 STM32F407IG，分别控制全向轮底盘与二轴云台；遥控接收机位于底盘板，两板通过 CAN 交换遥控、姿态、模式和安全状态。

## 当前状态

- 基础 1~10 项已完成：双板通信、全向轮解算、云台闭环、分离/跟随/小陀螺、云台坐标系平移、急停/失联归零和双板看门狗。
- 实车已验证前后、左右、三模式、失联恢复、Pitch 顶部抗扰和小陀螺落地复合运动。
- 2026-11-17 按实车正前方重标定 `kYawOffset=2.12100 rad`，固件已烧录并通过 Flash 校验；最终提交前仍应做一次上电回正复核。
- 双板 CAN 物理断联及恢复已于 2026-11-16 完成现场验证；主机自动测试同时覆盖双向/单向断链与恢复。
- PID 原始 CSV、曲线及绘图脚本保存在 `pid_capture/`。

## 构建

需要 ARM GNU Toolchain、CMake 和 Ninja。分别在两块板目录执行：

```powershell
cmake --preset Debug
cmake --build --preset Debug
```

输出位于各工程的 `build/Debug/`，构建产物不提交到仓库。

## 主机测试

在 WSL/Linux 安装 `g++` 后执行：

```bash
cd omni_skeleton
bash tests/run.sh
```

测试使用 AddressSanitizer 和 UndefinedBehaviorSanitizer，覆盖协议、DBUS、PID、运动学、双板状态机、故障恢复和 IMU/Mahony。真实中断时序、接线、机械限位和实车 PID 效果必须按现场流程验证。

## 核心约定

- 平移命令始终定义在云台坐标系：`x` 为枪管方向，`y` 为云台左方。
- `vx > 0` 始终沿枪管方向前进，与底盘车头朝向无关。
- 左拨杆向下为急停；右拨杆上/中/下对应分离/跟随/小陀螺。
- 安全事件绕过平滑器并立即清零；恢复时先将目标对齐当前姿态，再重新进入闭环。
- 所有现场可调增益、限幅、轮位和零点集中在 `omni_skeleton/RobotComponents/component/robot_config.hpp`。

## 设计取舍

代码中用 `DESIGN TRADE-OFF` 标出验收时需要说明的取舍，主要包括：

- 100 ms 通信超时在快速保护与偶发丢帧容错之间折中。
- 小陀螺降低平移/旋转上限，以牺牲峰值速度换取供电和驱动可靠性。
- 四轮同比缩放而非逐轮裁剪，保留合成速度方向。
- Pitch 保留机械安全余量，牺牲少量行程避免持续顶限位。
- Pitch 使用受限积分补偿重力和静摩擦，并限制阻塞后的释放冲击。
- Yaw 增加电机侧速度阻尼，以少量响应时间换取更小超调。
- 任一板异常时两板共同进入保护，恢复前重新对齐目标，避免旧指令突跳。
